# Информационная система управления парком корпоративного автотранспорта (Corporate Fleet Management System)

## Концепция системы
Система предназначена для автоматизации процессов управления корпоративным автотранспортом. Она позволяет вести учет транспортных средств (ТС), контролировать распределение автомобилей между сотрудниками, планировать техническое обслуживание (ТО), отслеживать путевые листы, расходы на топливо (ГСМ) и страхование (ОСАГО/КАСКО).

### Основные модули:
- **Учет ТС:** Паспорта машин, пробег, технический статус.
- **Управление заявками:** Бронирование автомобилей сотрудниками и согласование поездок.
- **Мониторинг расходов:** Учет затрат на топливо, ремонты, штрафы.
- **Аналитика и отчеты:** Расчет TCO (общей стоимости владения) и загрузки автопарка.

## Технологический стек
- **Backend:** Python 3.11, FastAPI (высокая производительность, автодокументация Swagger).
- **Frontend:** TypeScript, React, TailwindCSS (адаптивный интерфейс для диспетчеров и водителей).
- **СУБД:** PostgreSQL (хранение реляционных данных о поездках и ТС), Redis (кеширование сессий и очередей).
- **Брокер сообщений:** Celery + Redis (для отложенных задач: отправка уведомлений о ТО).
- **Контейнеризация:** Docker, Docker Compose.

## Инструкции по развертыванию (Локально)

### Предварительные требования
- Установленный [Docker](https://docker.com) и Docker Compose.

### Быстрый запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd fleet-management-system
   ```
2. Скопируйте файл конфигурации окружения:
   ```bash
   cp .env.example .env
   ```
   *(При необходимости отредактируйте параметры БД в `.env`)*

3. Запустите проект в Docker:
   ```bash
   docker-compose up --build -d
   ```
4. Система будет доступна по адресам:
   - Frontend: `http://localhost:3000`
   - Backend API (Swagger): `http://localhost:8000/docs`
